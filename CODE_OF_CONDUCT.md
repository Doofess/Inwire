# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The short version, which is the part that actually gets used:

**Be decent to people.** Harassment, personal attacks, and demeaning or
unwelcome comments about anyone are not acceptable here, in issues, in pull
requests, in review comments or anywhere else this project has a presence.
Disagree about the code as much as you like — that is what the issue tracker is
for — and argue the decision rather than the person who made it.

**Assume the other person is doing their best with what they know.** A report
that turns out to be user error, a pull request that misses a constraint written
down somewhere they never looked, a question already answered in `CLAUDE.md` —
none of those deserve a sharp answer. If the documentation was unclear, that is
a thing to fix.

## Reporting

This is a single-maintainer project, so there is no committee. Report a problem
privately through GitHub's
[report abuse](https://github.com/contact/report-abuse) form, which reaches
GitHub Support directly and does not depend on the maintainer being the right
person to hear it, or by contacting the maintainer through their GitHub profile.

Reports are handled privately. The maintainer may remove comments, close
threads, or block accounts, and will say that something was removed rather than
doing it silently.
