# Rejected concepts

One file per concept that was asked for, or might be, and was decided against. `/triage` reads these before recommending a state; a request that matches one closes as not planned with a link to the file. A file records the concept, the reason, and the decision it rests on, so the argument is not re-run. Add a file when an enhancement is rejected; never for something already built (point to the code instead).
