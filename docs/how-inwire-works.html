Twelve diagrams, each a set of cards joined by labelled arrows. A card is a process, a module or a file; an arrow is something that moves, and its label says what. Colour says which process a card belongs to, and the colours are the same on every page.

Drawn from the repository as of 2026-09-18: CLAUDE.md, the ADRs, and the source tree. Where a card names a file in monospace, that file exists and holds the decision.
